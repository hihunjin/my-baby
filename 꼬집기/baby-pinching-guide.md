# 아기 꼬집기, 장기화 전에 잡는 법

> 대상: 지금 10개월 무렵, 엄마·아빠를 꼬집기 시작한 지 꽤 된 아기
> 근거: ZERO TO THREE, AAP(HealthyChildren), Raising Children Network(호주), Tusla(아일랜드), NAEYC, KidsHealth, AACAP, 육아정책연구소·경기북부육아종합지원센터 안내서, Tremblay 등 공격행동 발달 연구
> 작성일: 2026-11-24

---

## 0. 먼저 결론

- **10개월 아기의 꼬집기는 공격이 아니라 실험이다.** 이 나이에는 일부러 아프게 할 사고 능력이 아직 없다(ZERO TO THREE). 9개월 무렵 생기는 집게잡기(엄지+검지)를 써보고, "꼬집으면 엄마가 '아야!' 한다"는 원인과 결과를 확인하는 중이다.
- **"장기화"의 진짜 의미는 꼬집기가 *보상받는 행동*으로 굳는 것.** 큰 리액션(웃음, 비명, 긴 설명), 꼬집으면 원하는 걸 얻는 경험이 행동을 키운다.
- **그래서 핵심은 매번 똑같이, 짧고 지루하게 반응하고, 대신 할 행동을 손에 쥐여주는 것.**
  1. 차분한 얼굴로 짧게: "아야. 꼬집으면 아파."
  2. 손을 부드럽게 떼어 잡는다.
  3. "살살~" 쓰다듬는 법을 보여주거나, 손에 쥘 것을 준다.
  4. 계속되면 몇 초간 내려놓거나 몸을 돌린다. 그 뒤엔 다시 다정하게.
  5. 살살 만졌을 때 바로, 크게 칭찬한다.
- **기대치:** 신체 공격 행동은 대부분 아이에게 첫돌 전후 시작해 **2~3세에 가장 많고, 4세부터 줄어든다**(Tremblay 등). 지금 완전히 없애는 게 목표가 아니라, 정점기(18개월~2.5세)에 *더 심해지지 않도록 길을 들이는 것*이 목표다.

## 1. 왜 꼬집을까 (10개월 기준)

| 원인 | 어떻게 보이나 | 근거 |
|---|---|---|
| **원인-결과 탐색** | 꼬집고 얼굴을 쳐다본다. 반응을 기다린다 | Tusla, Happiest Baby: "결과를 배우려고 반복한다" |
| **집게잡기 발달** | 피부·목걸이·점·작은 살을 집는다 | Happiest Baby: 9개월 무렵 집게잡기 |
| **흥분·과자극** | 신나게 놀다가, 안겨서 깔깔대다가 | ZERO TO THREE, Tusla |
| **졸림·배고픔·이앓이** | 잠들기 전, 수유 중, 저녁 시간대 | Tusla, Raising Children, Pathways(수유 중 꼬집기) |
| **관심 끌기** | 부모가 폰을 보거나 다른 일을 할 때 | Tusla, KidsHealth |
| **말 대신 표현** (12개월 이후 증가) | "싫어", "내려줘", "그거 줘"를 손으로 | ZERO TO THREE, 육아정책연구소 |

> 2주 정도 **언제·어디서·누구에게** 꼬집는지 메모해 보면 패턴이 나온다. 대처의 절반은 패턴 파악이다.

## 2. 꼬집는 순간, 이렇게 (매번 똑같이)

| 단계 | 하는 것 | 이유 |
|---|---|---|
| ① 멈춤 | 표정은 차분, 목소리는 낮고 짧게. "아야. 꼬집으면 아파." / "꼬집지 않아." | 강한 반응은 재미있는 결과가 되어 반복을 부른다 (Happiest Baby) |
| ② 손 떼기 | 아기 손을 부드럽게 떼어 잠깐 감싸 쥔다 | ZERO TO THREE: 손을 부드럽게 잡고 "꼬집지 않아" |
| ③ 바꿔주기 | "살살~" 하며 아기 손으로 내 팔을 쓰다듬게 한다 / 치발기·말랑 장난감을 쥐여준다 | 하지 말라는 것만 말고 *대신 할 것*을 준다 (ZERO TO THREE, Happiest Baby) |
| ④ 관심 빼기 (반복 시) | 몇 초간 바닥에 내려놓거나 몸을 돌린다. 화내지 않고, 길지 않게 | 꼬집기 → 재미가 끝남을 배우게 (Tusla, Raising Children) |
| ⑤ 다시 연결 | 곧바로 다정하게 다시 안거나 놀아준다 | 벌이 아니라 "꼬집으면 놀이가 멈춘다"는 신호 |
| ⑥ 칭찬 | 살살 만졌을 때 놓치지 말고 "살살 만져줬네! 기분 좋다" | 원하는 행동을 강화 (Tusla, AAP) |

### 말 대본

**지금(10~12개월):** 말은 짧게, 같은 단어를 계속.
- "아야. 아파." → (손 떼고) → "살살~" → (쓰다듬게) → "그렇지, 살살."

**12개월 이후:** 감정 이름 붙이기 + 한계 + 대안.
- "졸려서 짜증 났구나. 그래도 꼬집으면 안 돼. 아파. 졸리면 '코~' 하자."
- "내려가고 싶었어? 꼬집지 말고 '내려' 하고 말해."
- ZERO TO THREE 원문 예: *"It's okay to be mad, but it is not okay to hit Mommy. Hitting hurts."*

**2세 무렵:** "싫으면 '싫어'라고 말하는 거야." (육아정책연구소·경기북부육아종합지원센터 안내서)

## 3. 하지 말 것

| 하지 말 것 | 왜 |
|---|---|
| **크게 웃기, "아악!" 과장 반응** | 아기에겐 최고의 장난감이 된다. 강한 반응은 반복을 부른다 |
| **같이 꼬집어서 "이게 아픈 거야" 가르치기** | 10개월은 이해 못 하고, "아픈 행동을 해도 된다"는 시범이 된다. 신체 체벌은 공격성을 키운다 |
| **화내기·소리 지르기** | "네가 화나면 나도 안 도움 된다" (Tusla). 흥분이 흥분을 부른다 |
| **긴 설명** | 이 나이엔 말의 내용이 아니라 반응의 크기만 전달된다 |
| **엄마는 참고 아빠는 혼내기 (불일치)** | 비일관성은 학습을 늦춘다 (Tusla). 조부모·돌봄 선생님과도 같은 말·같은 순서로 |
| **꼬집으면 원하는 걸 주기** | 공격으로 목적을 이룬 경험은 공격성을 강화 (육아정책연구소) |
| **"꼬집쟁이" 라벨 붙이기** | 라벨이 아이의 자기 이미지가 된다 (NAEYC) |

## 4. 꼬집기 전에 막기 (예방)

- **패턴 시간대 미리 대응:** 졸릴 때 꼬집는다면 잠 신호를 일찍 잡아 재우기. 수유 중이면 손에 쥘 것(수유 목걸이, 천 인형, 부모 손가락) 미리 주기.
- **손을 바쁘게:** 안을 때 한 손에 장난감. 집게잡기 욕구를 채울 놀이(뚜껑 열기, 퍼즐 손잡이, 스티커 떼기, 작은 핑거푸드 집기).
- **표적 줄이기:** 목걸이·늘어진 귀걸이 빼기, 목·팔 안쪽 살 노출 줄이기 (Happiest Baby).
- **손톱 정리:** 꼬집기는 못 막아도 상처는 줄인다.
- **"살살" 놀이:** 인형·반려 인형을 쓰다듬는 놀이, 부모 얼굴을 살살 만지는 놀이로 '부드러운 손'을 연습. 될 때마다 칭찬.
- **흥분 조절:** 놀다가 텐션이 오르면 미리 템포를 낮추기(조용한 노래, 안아서 흔들기).
- **관심의 시간 충분히:** 꼬집어야 관심을 받는 구조가 되지 않게, 평소에 눈 맞추고 놀아주는 시간을 확보.

## 5. 얼마나 갈까, 언제 상담할까

### 발달 경로 (연구)
- Tremblay 등 캐나다 코호트: **대부분 아이가 17개월까지 신체적 공격(때리기·꼬집기·물기 등)을 이미 시작**한다.
- 빈도는 **2~3세에 정점, 4세부터 감소**하는 곡선 (Alink 2006 리뷰).
- Happiest Baby: 때리기·물기·잡아당기기는 **18개월~2.5세**에 가장 많다.
- 부모 포럼 일화: 11개월에 시작해 14개월쯤 줄어들었다는 경우가 흔하다 (Mumsnet; 일화이므로 참고만).
- Illinois Extension: 대부분 아이는 **3세까지** 물기·공격 없이 감정을 표현할 수 있게 된다. **3세 이후에도 잦으면** 의료진과 상담.

### 이럴 땐 상담
- 3세 이후에도 자주, 세게 반복된다
- 말·눈맞춤·호명 반응 등 **다른 발달이 함께 걱정**된다
- 자기 몸을 꼬집거나 다치게 한다
- 부모가 지치고 화가 나서 일상이 힘들다 (Tusla: 부모의 지침도 상담 이유)
- **다음 영유아건강검진(3차, 9~12개월 / 4차, 18~24개월) 때 소아청소년과에 물어보기**에 좋은 주제. 각 지역 육아종합지원센터에도 행동 상담이 있다.

## 6. 한 장 요약 (냉장고용)

```
꼬집으면
  1. 차분한 얼굴, 낮은 목소리: "아야. 아파."
  2. 손 떼서 감싸 쥐기
  3. "살살~" 쓰다듬기 / 쥘 것 주기
  4. 또 하면: 몇 초 내려놓기 → 다시 다정하게
살살 만지면
  → 바로 칭찬 "살살 만져줬네!"
절대
  웃기 X  같이 꼬집기 X  화내기 X  어른마다 다르게 X
```
